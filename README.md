# Pizza Sales SQL Analysis

## Project Overview

This project analyzes pizza sales data using SQL.

The analysis covers:

- Total orders
- Total revenue
- Most ordered pizza
- Revenue contribution
- Hourly order trends
- Category-wise analysis
- Cumulative revenue analysis

## Database Schema

Tables used:

1. orders
2. order_details
3. pizzas
4. pizza_types

## SQL Concepts Used

- Joins
- Aggregate Functions
- Group By
- CTEs
- Window Functions
- Subqueries

## Business Questions Solved

### Basic

1. Retrieve total number of orders
2. Calculate total revenue
3. Highest priced pizza
4. Most common pizza size
5. Top 5 ordered pizzas

### Intermediate

1. Quantity ordered by category
2. Orders by hour
3. Category distribution
4. Average pizzas ordered per day
5. Top 3 pizzas by revenue

### Advanced

1. Revenue contribution %
2. Cumulative revenue analysis
3. Top 3 pizzas by revenue in each category

- MySQL
